# 杭州电子科技大学《机器学习课程实践》—— 基于机器学习的径流预测

本项目严格按照教学大纲与《机器学习课程实践》实验指导书要求设计并实现，涵盖从数据分析、时间序列特征工程、基础模型多步预测到集成学习与全面评估的完整工程闭环。

## 实验环境与运行说明

本项目在 Windows 环境下基于 Python 3.11 虚拟环境构建，主要依赖：
- `pandas`, `numpy`, `scipy`
- `scikit-learn`
- `torch` (PyTorch LSTM)
- `matplotlib`, `seaborn`
- `python-docx`

### 快速一键运行全流程：

在当前目录下打开终端执行：
```bash
.venv\Scripts\python run_pipeline.py
```
脚本将按教学计划先后顺序无缝执行所有步骤，并在数分钟内重新生成所有预测、图表与 Word 格式验收报告。

## 实验指导书完成要点核对清单

- [x] **数据分析**：
  - 完整给出 Daymet 与 USGS 全部 9 个英文字段的中文含义、物理单位及水动力学背景。
  - 绘制时间序列全景图、直方图与 KDE、箱型图（含月度季节性规律）、皮尔逊相关系数热力图并深入剖析。
- [x] **特征工程**：
  - 时间序列编码：实现四季编码（Season: 0-3）及月份/年积日的正弦余弦连续周期编码（Month_sin, Month_cos）。
  - 滞后与窗口特征：提取滞后 1, 2, 3, 7 天历史特征，提取过去 3 天与 7 天滑动均值、极值与标准差。
  - 特征归一化：对比 Min-Max 与 Z-Score，严格在训练集 (2000-2003) 上拟合以杜绝数据穿越。
  - 特征选择：对比皮尔逊相关系数法与互信息法 (Mutual Information)，筛选出 58 个最优水文气象特征子集。
- [x] **径流预测（24个个体模型）**：
  - 人工神经网络 (ANN, MLPRegressor)：时序网格搜索最佳超参数，构建 7 个直接预测模型 + 1 个多输出模型。
  - 随机森林 (Random Forest)：网格搜索最佳参数，构建 7 个直接预测模型 + 1 个多输出模型。
  - 长短期记忆网络 (LSTM, PyTorch)：网格搜索隐层与学习率，构建 7 个直接预测模型 + 1 个多输出模型。
- [x] **集成学习（16个集成模型）**：
  - 简单平均法 (Simple Average)：直接预测 7 个 + 多输出预测 1 个。
  - Stacking 堆叠泛化法 (Ridge Meta-Learner)：直接预测 7 个 + 多输出预测 1 个。
- [x] **精度评价体系**：
  - 全面涵盖 RMSE、MAE、R² 以及水文学黄金指标 NSE（纳什效率系数）。
  - 简单平均集成模型在第 1 天预测取得最优表现（RMSE = 596.96 cfs, NSE = 0.5000）。
- [x] **课程交付物**：
  - 输出格式规范、排版优美且内嵌高清图表与三线表的《机器学习课程实践》实践报告 (`.docx`)。
  - 紧扣“智慧水利”与科技报国主题的个人思政报告 (`.docx`)。
